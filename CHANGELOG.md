# Tvaro IPTV changelog

## 0.1.2 — 2026-10-30

### New

- Tvaro IPTV has a new name and app icon
- A new setup wizard in English and Arabic

### Improved

- Cards, panels and placeholders now follow your theme colour
- The window reopens maximized if you left it maximized
- More room under Arabic titles on the home screen
- Stream information shows a simple player name

### Fixed

- Changing the theme on one profile no longer changes it on other profiles
- Release downloads no longer list files you don't need

## 0.1.1 — 2026-10-30

- Redesigned player options: one clean list with a check on the current choice
- Lower memory use during playback and while the window is minimized
- Large playlists and TV guides load with far less memory
- Updates now come from GitHub Releases

## 0.1.0 — 2026-10-30

- First desktop release for Windows
